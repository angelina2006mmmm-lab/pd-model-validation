# Document Vision Lab — PyTorch CV for synthetic document layouts

**Educational portfolio** for a Computer Vision ML Engineer internship, focused on classification of synthetic document-like images and end-to-end ML engineering. NOT a banking OCR system, personal-data extraction or production VLM.

## Verified local experiments

- **Dataset:** 660 programmatically generated 96×64 RGB images representing three synthetic layouts: card, passport-like page and driver's license-like page. Stratified class splits: 450 train, 105 validation, 105 test. No real personal data.
- **Quality control:** decoding, RGB/shape, split/class coverage, SHA-256 duplicate detection, reproducible per-image seeds.
- **PyTorch architecture comparison:** CNN (**37,747** parameters) and ViT-like patch TransformerEncoder (**57,171** parameters), AdamW training, best validation checkpoint.
- **Held-out synthetic test:** CNN accuracy/macro F1 **1.00/1.00**, tiny ViT accuracy/macro F1 **1.00/1.00** (105 test templates each). This is deliberately easy synthetic imagery and NOT a result on real documents.
- **Stress-test of CNN on the same held-out samples:** original accuracy **1.0000**, blur σ=2 px **0.9619**, 50% brightness **0.3333**, 12° rotation **1.0000**. Accuracy drops heavily under darkness; this failure is documented rather than hidden.
- **Serving:** TorchScript model export; FastAPI /predict (image/png|jpeg|webp, 2 MB limit, strict validation) + /health; API/inference integration tests.
- **Engineering:** pytest, reproducible dataset generation, CI training/evaluation, configured DVC pipeline. An optional MLflow adapter is included but DVC and MLflow execution have **not** been verified; these are configurations, not demonstrated experience.

## Reproduce locally

    python -m pip install -r requirements.txt
    python -m pytest -q tests/
    python -m docvision.train --model cnn --epochs 5
    python -m docvision.train --model vit --epochs 5
    python -m docvision.stress
    uvicorn docvision.server:app --port 8000

Sample request, using an image generated by the dataset script:

    curl -H 'Content-Type: image/png' --data-binary @data/test/bank_card/bank_card_40042.png http://127.0.0.1:8000/predict

If no images are present, the training script creates the dataset. Logs/metrics are stored locally under artifacts/ and reports/. GitHub Actions runs the full training and uploads metrics as a workflow artifact.

## Limits / next steps

- The images are simple synthetic layouts, NOT photographs of authentic documents; high accuracy does not imply readiness for passport OCR, real card recognition, VLM field extraction, or customer data.
- Add a legally sourced privacy-safe labeled document benchmark, annotation checks, geometry augmentation, out-of-distribution validation and leakage-resistant splitting.
- Benchmark pretrained MobileNet/EfficientNet and real ViT backbones; add layout detection, OCR CER/WER and VLM field extraction exact-match.
- Benchmark batch size, P50/P95 server latency, memory and quality/performance on real mobile/server hardware.
- Model / data privacy compliance would require an independent review for production deployment.
